<h1>
  <span class="headline">Document a Technical Process Lab</span>
  <span class="subhead">Instructor Guide</span>
</h1>

One of the most essential skills for students training for a technical role, is writing clear and concise documentation. This lab will provide students with an opportunity to sharpen their technical writing skills by allowing them to practice documenting a technical process of their choice.

The final product of this assignment should result in a single Markdown file in a repo on GitHub Enterprise containing a documented technical process.

A short guide on Markdown essentials in provided in the lab setup along with a link to the official [GitHub Flavored Markdown Guide](https://guides.github.com/features/mastering-markdown/).
