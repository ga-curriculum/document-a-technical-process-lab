## Lab requirements

The following requirements describe the necessary deliverables for the lab and the points awarded out of 100 for each piece of functionality.

| Criteria                                                                                                                                        | Points |
| ----------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| The <code class="filepath">README.md</code> file clearly identifies the technical process that it documents.                                    | 10     |
| The <code class="filepath">README.md</code> file includes a description of the technical process, including its purpose.                        | 10     |
| The <code class="filepath">README.md</code> file includes a list of prerequisites including necessary tools, permissions, or software required. | 10     |
| The <code class="filepath">README.md</code> file is formatted in a clear manner.                                                                | 10     |
| The <code class="filepath">README.md</code> file has technically complete, accurate, and logically ordered steps.                               | 30     |
| The <code class="filepath">README.md</code> file has uses clear and professional language.                                                      | 10     |
| The steps in the <code class="filepath">README.md</code> file can be followed by a person unfamiliar with the process.                          | 10     |
| **Total possible points**                                                                                                                       | 100    |
